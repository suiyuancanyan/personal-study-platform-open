# 我的学习台

我的学习台是一个在本机运行的中文学习平台，覆盖模拟电子技术、信号与系统和大学物理。每门课包含图文讲解、交互实验、分步例题和自测。学习进度、笔记和错题保存在当前浏览器。

## 开始使用

安装 Node.js 22 或更高版本，在仓库目录运行以下命令。

```sh
node pilot/serve.mjs
```

打开 [课程目录](http://127.0.0.1:3210/) 即可开始学习。课程、实验和内置练习无需额外安装依赖或配置 API 密钥。

## 可选配置

- **AI 伴学**支持 Codex 和 DeepSeek。Codex 使用本机已登录的命令行工具。DeepSeek 可在伴学面板输入 API 密钥，也可在启动前设置 `STUDY_DEEPSEEK_API_KEY`。使用伴学时，提问及当前课节上下文会发送给所选服务。
- **本地课件**可通过 `STUDY_SOURCE_ROOT` 指定资料目录。目录结构和文件名见 `pilot/course-pages.mjs` 与 `pilot/chapters.mjs`。公开版使用内置图解和练习，个人课件和题目截图由使用者自行保管。
